# Public-release and deployment check

Checked 9 November 2026. Public project: **Danish Health & Life Expectancy**.

## Release to publish

Use the contents of `public_release/`, generated by:

```sh
python -m scripts.prepare_public_repository --output public_release
```

Do not upload the entire working directory. The working copy deliberately preserves private raw acquisition records and original provenance. Its legacy ignore rules exclude runtime files; the generated public repository has a separate ignore file that includes all required processed data and saved outputs.

The exporter includes a checksum ledger, preserves observation/statistical CSVs and figures/PDFs byte-for-byte, and redacts local filesystem strings in metadata copies. Dependent checksum records are updated only in the release. This is metadata packaging, not a rerun or revision of the analysis.
